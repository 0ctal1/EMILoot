# EMI Loot for Better Than Wolves CE

1. Run `install.bat` (Windows) or `install.sh` (Linux/macOS).
2. Run `gradlew build` to build the addon (it will show up in `build/libs/`).
4. Put it in your BTW instance's `mods` folder (use the one **WITHOUT** `-sources` / `-dev`).

To test in the dev environment: `gradlew runClient`. \
Requires JDK 17
